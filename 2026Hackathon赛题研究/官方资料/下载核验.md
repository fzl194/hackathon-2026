## 原图、OCR 与文字恢复

- 第 23、31 题正文基本全部为图片；第 22 题也包含大量图片内容。`原文.md` 保留官方原图，这三题另有 `原文_OCR.md` 便于检索。OCR 可能误识别变量、数字、上下标、公式或代码，正式要求与评分以原图为准。
- 第 04 题有一个不含图片地址的官网内嵌节点，其 `data-equation` 字段误包了 1,152 个字符的评委程序调用与协议说明。已按 URL 编码完整解码并补回 Markdown；未改写内容。原始 JSON 和 HTML 可供复核，`manifest.json` 中的 `decoded_embedded_content` 记录恢复文字。
- 其他公式图片均本地保存；全文提取不依赖网页摘要。JSON、HTML 与 Markdown 三种形式共同保留原始证据。

## 附件与外部链接边界

已实际检查公开详情的 `attachments`、正文链接和返回的元数据。正文包含外部论文、代码仓库、公开数据包、内核安装包和文档等参考链接，原文与 `manifest.json` 已保留可定位的链接；这些外部资源未批量下载，不能视为已取得的比赛官方开发包或官方数据。

当前尚未取得需由组委会提供的比赛数据、开发包、评测器或比赛环境。附件字段为空仅表示当前公开接口未列出附件，不能据此断言赛事没有这些材料。各题关于赛前/赛时资料发布的要求仍按官方正文分别记录。
