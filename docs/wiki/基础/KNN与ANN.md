# KNN与ANN：需求、精确答案和近似搜索

[Wiki首页](../README.md) · 前置：[概念地图](概念地图.md) · 下一页：[KD-tree](../算法/KD-tree.md)

KNN搜索要求找最近的K个点；ANN搜索允许一定遗漏，以换取更快的查询。两者都不是特指某一种数据结构。

## 先分清KNN搜索与KNN分类

- KNN搜索：找出距离查询最近的K个样本。
- KNN分类：先找这K个样本，再根据它们的类别投票。

本题关注搜索，可以先拿掉分类和投票步骤。查询结果是近邻编号或记录。

## 暴力精确解是参照答案

给定N个d维向量，逐个计算与查询q的距离，再用大小K的堆维护候选。距离计算约O(Nd)，堆维护约O(N log K)。这不一定是最快的精确实现，但直观且便于验证。

例如q=(0,0)，A=(1,0)、B=(0,2)、C=(3,4)，欧氏距离依次为1、2、5，精确Top-2就是A、B。

## 精确与近似的分界

精确搜索也可以跳过数据，但必须保证跳过后不影响精确答案。[KD-tree](../算法/KD-tree.md)的距离下界剪枝就是例子。

ANN是Approximate Nearest Neighbor的缩写。很多方法通过搜索部分分区、部分图节点，或采用压缩表示减少工作；不再要求每次都找回全部精确近邻。

|方式|跳过数据的依据|结果要求|
|---|---|---|
|精确搜索|能够证明被跳过区域不会改善答案|精确Top-K，距离并列按接口规则处理|
|近似搜索|搜索预算、结构或近似判断|可能遗漏，需用召回率等指标测量|

精确搜索也可能使用压缩后的数据作为目标表示；ANN也可能对访问到的原始向量精确计算距离。“是否遗漏候选”与“距离计算是否采用近似表示”是两个维度。

## “传统ANN”是什么

没有一个唯一算法叫传统ANN。说话者可能泛指树、哈希、分区、图等既有近似方法，也可能强调主要为内存设计的实现。必须看上下文中的具体方法和版本。

## 与本题的关系

我们需要先有小数据精确参照，再评估快速搜索找回了多少。允许的搜索遗漏不能成为事务可见性错误、返回非法记录或算错距离公式的理由。
