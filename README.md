
目标是可编译、可复现的PostgreSQL扩展，支持受限内存下的磁盘ANN、高维、过滤及动态更新，并通过事务与并发验证。提交物包括源码、Dockerfile、参数扫描配置和不超过8页的报告。

后续使用AI辅助开发与实验，先建立可信验证闭环。官方题面和第三方资料保留原作者及来源；本项目不为第三方内容另行添加许可证。旧选题研究已从当前工作区移除，历史版本可通过Git追溯。
