## 版本管理范围

仓库保存原文、解读、研究汇总、Excel 和 181 张正文图片。临时研究脚本、依赖目录、渲染预览、旧稿和重复压缩包不纳入 Git。

官方赛题与第三方论文、文档和代码保留原作者及来源信息。本仓库没有为第三方资料添加新的开源许可证。
