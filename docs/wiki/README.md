# 第14题知识 Wiki

面向熟悉编程与算法、没有数据库背景的读者。按概念独立成页，可以顺序学习，也可以遇到陌生词时直接查阅。

本文档记录已讲解的知识，不代表已经实现扩展或完成实验。embedding基础定义不再单独重复；重点衔接KNN、空间数据结构、磁盘检索和数据库机制。

## 已有手推专题

理解概念后，沿同一组8个二维点继续读：[KD-tree查询手推](算法/KD-tree查询手推.md) → [IVF查询手推](算法/IVF查询手推.md)。前者用包围盒下界证明可以跳过，后者展示有限搜索预算怎样漏掉近邻，以及为什么重排无法补回未进入候选的点。

继续沿同一组点读：[HNSW查询手推](算法/HNSW查询手推.md) → [HNSW多层导航](算法/HNSW多层导航.md)。人工图分别演示单路径局部最优、待扩展队列与较好候选集、ef预算，以及上层怎样提供底层入口。

理解查询后继续读：[HNSW插入与选边手推](算法/HNSW插入与选边手推.md) → [HNSW参数与构建代价](算法/HNSW参数与构建代价.md)。观察新节点怎样选邻居、为什么近点可能重复覆盖，以及M和efConstruction怎样分工。
