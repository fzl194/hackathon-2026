## 使用前提与研究范围

按三人团队、较少GPU、提前约14天暂时拿不到官方数据、现场24小时必须交付进行分析。解读面向懂编程但不熟各行业背景的读者，先以日常类比解释，再讨论具体机制、评分、实现与局限。

“第一项实验”是建议设计，尚未执行；“工时”是规划估计，尚未用官方数据实测。已有论文或开源实现并不等于能原样提交，必须检查参数规模、接口、架构、离线要求、许可和评分口径。原文冲突或遗漏仍明确列为待确认。

允许AI辅助准备与开发，是用户提供的决赛信息；提交程序能否联网或调用模型按每题独立规则处理。官网赛程图给出决赛及颁奖10月30日至11月1日，没有给出其中24小时的精确起止；准备计划按相对天数。[官方赛程](官方资料/大赛进程.png)。

## Excel字段说明

“逐题调研结论”包含问题本质、调研发现、入口与首个实验；“技术与实施条件”包含官方评分、训练、数据、技术栈、硬件、难度、准备/现场人时、核心突破点与未知；“研究依据”逐条列明来源用途及限制。字段按技术研究与实施条件组织。

技术难度1—5表示实现复杂程度，5最难；这不是选题评分。工时单位为人时，前提为三人只实施这一题且已准备最小闭环。三人现场理论72人时，有效45—55人时仅为规划假设，必须用自己的演练校正。
