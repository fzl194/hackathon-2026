# 技术来源

只保留第14题相关入口。2026-10-21重新核对了pgvector、pgvectorscale、VIBE及NeurIPS23说明页面；尚未下载全量基准、编译扩展或运行性能测试。实际实现须锁定版本/提交，不直接依赖会变动的main分支。

|资料|用途|边界|
|---|---|---|
|[官方题面](赛题原文.md)、[原始响应](../official/赛题14.json)|任务、接口、数据、评分和淘汰条件|没有同时取得正式开发包|
|[pgvector](https://github.com/pgvector/pgvector)|类型/距离、精确查询参照、PG集成及ANN基线|类型存储与索引维度限制不同，不等同完整磁盘方案|
|[pgvectorscale](https://github.com/timescale/pgvectorscale)|StreamingDiskANN、量化、过滤和重评分入口|距离/标签/并行构建等差距需逐项验证|
|[DiskANN](https://github.com/microsoft/DiskANN)|磁盘ANN算法和实现研究入口|独立库不自动满足PG事务、WAL与规划器集成|
|[ANN-Benchmarks](https://github.com/erikbern/ann-benchmarks)|核心ANN数据、参数扫描和召回—吞吐曲线|比赛的PG调用和评分包装待确认|
|[VIBE项目](https://github.com/vector-index-bench/vibe)、[作者数据入口](https://huggingface.co/datasets/vector-index-bench/vibe)|3072维及现代embedding基准|需核对实际数据文件/条数/版本，不能仅看数据集名|
|[Big-ANN](https://github.com/harsha-simhadri/big-ann-benchmarks)、[数据集定义](https://github.com/harsha-simhadri/big-ann-benchmarks/blob/main/benchmark/datasets.py)|BIGANN、YFCC及MSTuring的数据和接口|上游环境不自动等同本次竞赛资源|
|[NeurIPS23规则与复现](https://github.com/harsha-simhadri/big-ann-benchmarks/blob/main/neurips23/README.md)|过滤、动态检查点、runbook与真值流程|不把上游其它赛道的时间/硬件直接套到本题|
|[PostgreSQL 18文档](https://www.postgresql.org/docs/18/)|扩展、索引访问方法、事务、WAL与资源设置|比赛基线仍按题面指定18.4及正式工具链锁定|

旧讨论中有用的标签提醒已保留：pgvectorscale公开README的smallint[]/OR overlap与本题大词表/AND要求有差距，不能把有过滤功能理解为已经通过本题过滤赛道。后续优先检查实际代码和回归，不只看README。

入门算法参考补充：[HNSW作者论文](https://arxiv.org/abs/1603.09320)、[DiskANN原论文](https://papers.nips.cc/paper_files/paper/2019/hash/09853c7fb1d3f8ee67a61b6bf4a7f8e6-Abstract.html)、[Faiss索引说明](https://github.com/facebookresearch/faiss/wiki/Faiss-indexes)。

本次还读取了作者VIBE原始Parquet汇总并保留四算法选点；公开成绩、硬件、K和召回口径详见[公开基准现状](公开基准现状.md)。这些外部成绩均不是本项目实测。
